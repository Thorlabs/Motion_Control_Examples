# Thorlabs XA Python SDK
This is the official Python SDK for the Thorlabs XA Motion Control Platform. The required binary file is included with the package and will be installed to the shared python directory. Please refer to the LICENSE file for details regarding the licensing of this package and its dependencies.

# Devices Currently Supported
KDC101, KST201, KPC101, and LTS150C/300C/600C.

# Tested Operating Systems
Win 10
Win 11
Linux Ubuntu WSL2 and Mint 22.2
ARM/x86_64

Support
